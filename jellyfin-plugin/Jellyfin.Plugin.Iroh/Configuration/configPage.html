Iroh Remote Access

Private remote access to this server over Iroh peer-to-peer connections. Settings here are applied by iroh-host, which runs separately from Jellyfin.

The saved policy needs an iroh-host restart before it takes effect. In Docker, restart the container.

Transport policy

Relay only and P2P only are best effort in this version. See docs/transport-policies.md for what is and is not guaranteed.

WebSockets

Changes apply within a few seconds; turning WebSockets off closes open ones. Normal requests are not affected. When IROH_WEBSOCKETS or IROH_WEBSOCKET_ORIGIN is set for iroh-host, that value is applied again each time the host starts.

Host connection

Ignored when JELLYFIN_IROH_CONTROL_URL is set, as it is in the Docker image.
Ignored when JELLYFIN_IROH_CONTROL_TOKEN or JELLYFIN_IROH_CONTROL_TOKEN_FILE is set.
